# История проекта

Этот файл хранит только контекст прошлых экспериментов. Он не является инструкцией по текущей установке или обязательным ожидаемым поведением.

## 2026-08-30: версия 0.1.1 — миграция T-Invest API и TLS-диагностика

- REST endpoint переведён с invest-public-api.tinkoff.ru на invest-public-api.tbank.ru.
- GetCandles и GetLastPrices переведены с figi на instrumentId.
- Ошибка транспорта Failed to fetch отображается как сеть/сертификат.
- Для целевого Windows-компьютера зафиксирована необходимость официальных сертификатов НУЦ Минцифры.

## 2026-04-29: стабильная ветка

В версии Projects были реализованы и проверены:

- отдельные ценовые буферы для каждого FIGI;
- выбор активной площадки по времени последней сделки;
- cooldown по тикеру;
- защита от смешения цен разных площадок;
- уникальный список тикеров в popup;
- Chrome Sync для интересных и скрытых тикеров;
- экспорт и импорт пользовательских списков;
- direct, search-flow и text fallback активации тикера;
- точный поиск результата через a.pro-menu-item.

Эта ветка выбрана базой 30 августа 2026 года.

## 2026-05-15: эксперимент с React/Redux bridge

В отдельной ветке Downloads исследовалась активация тикера через внутренние структуры терминала:

- поиск React fiber;
- получение Redux store;
- перехват dispatch;
- вызов обработчиков selectSymbol и updateWidgetSymbol;
- экспериментальный выбор цветной группы виджетов.

Цветные группы не были подтверждены как рабочий механизм терминала.

Во время исследования небезопасная объектная сигнатура попала в state виджета. Терминал сохранил объект в серверном workspace, после чего перестал открываться с React error 31.

Для аварийного восстановления был добавлен MAIN-world sanitizer, который перехватывал JSON-ответы window.fetch и пытался заменить объектные ticker/symbol на строки.

## Почему эксперимент отключён

К 30 августа выяснилось:

- в bridge оставался перебор опасных объектных аргументов для неизвестных handlers;
- sanitizer выполнялся на каждой странице терминала и имел слишком широкую область воздействия;
- UI цветных групп противоречил фактически найденной модели widgetId;
- стабильные исправления сканера и синхронизации из Projects не были перенесены в майскую ветку;
- search-flow в майской ветке снова использовал ранее исправленный неточный селектор.

Поэтому terminal-bridge.js и sanitize-bootstrap.js удалены из активной рабочей версии.

## Резервная копия

Состояние экспериментальной ветки перед переключением было сохранено 30 августа 2026 года в отдельный локальный архив. Архив не входит в репозиторий и не является релизом. Не устанавливать экспериментальную ветку на компьютер пользователя и не запускать её на живом торговом аккаунте.

## Правило для будущих исследований

- Не перебирать неизвестные сигнатуры обработчиков на живом аккаунте.
- Не передавать объекты в ticker/symbol handlers без подтверждённого контракта.
- Не изменять серверный workspace во время discovery.
- Любую интеграцию с внутренностями React/Redux тестировать в изолированной среде.
- Implementation observation не превращать в обязательное требование без отдельного источника.
