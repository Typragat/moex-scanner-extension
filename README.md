# MOEX Price Scanner

Chrome-расширение для веб-терминала Т-Инвестиций. Оно опрашивает котировки MOEX, ищет резкие изменения цены за выбранное окно и показывает их в отдельном виджете.

Эта документация описывает стабильную ветку, восстановленную 30 августа 2026 года из версии Projects. Экспериментальная интеграция через внутренности React/Redux терминала в активную версию не входит.

## Важно перед использованием

- Расширение является вспомогательным индикатором, а не торговой рекомендацией.
- Для Windows используйте актуальную стабильную версию Google Chrome.
- Для доступа к T-Invest API в Chrome должны быть установлены корневой и выпускающий сертификаты НУЦ Минцифры РФ.
- На странице chrome://extensions должна быть включена только одна копия MOEX Price Scanner.
- Для реальной работы пока выбирайте окно 60, 120 или 300 секунд.
- Окно 600 секунд отображается в интерфейсе, но рассчитывается некорректно из-за шестиминутного буфера. Это известный баг.
- После открытия или перезагрузки терминала возможны преждевременные сигналы до полного накопления выбранного окна. Это также известный баг.

## Установка на Windows

1. Установите корневой и выпускающий сертификаты НУЦ Минцифры по официальной инструкции: https://www.gosuslugi.ru/crt
2. Полностью закройте Chrome, включая фоновые процессы, и запустите его снова.
3. Распакуйте папку расширения в постоянное место, например Документы\MOEX-Scanner.
4. Откройте Google Chrome.
5. Перейдите на chrome://extensions/.
6. Включите Режим разработчика.
7. Нажмите Загрузить распакованное.
8. Выберите папку, внутри которой непосредственно лежит manifest.json.
9. Убедитесь, что в списке осталась только одна включённая копия MOEX Price Scanner.
10. Закрепите расширение через меню Расширения в панели Chrome.

После обновления файлов нажмите Обновить на карточке расширения, затем перезагрузите терминал сочетанием Ctrl+Shift+R.

### Обновление через Git на Windows

Для обычного обновления запустите двойным кликом update-extension.cmd в папке расширения. Скрипт:

- проверит наличие Git и remote origin;
- остановится, если обнаружит локальные изменения;
- выполнит только безопасное обновление без merge-коммита через git pull --ff-only;
- покажет старый и новый commit;
- откроет chrome://extensions/ в Google Chrome.

После успешного запуска:

1. Найдите карточку MOEX Price Scanner.
2. Нажмите кнопку с круглой стрелкой Обновить.
3. Вернитесь в терминал и нажмите Ctrl+Shift+R.

Скрипт не требует прав администратора, не читает токен и не закрывает Chrome принудительно. Полностью автоматическая перезагрузка unpacked-расширения потребовала бы небезопасного управления браузером, поэтому один ручной клик оставлен намеренно.

Не переносите репозиторий в другую папку после подключения к Chrome. При смене пути Chrome может зарегистрировать новую unpacked-копию с другим локальным ID, и токен потребуется ввести заново.

## Получение токена T-Invest API

1. Откройте настройки Т-Инвестиций: https://www.tbank.ru/invest/settings/api/
2. Создайте токен с доступом Только чтение.
3. Скопируйте токен сразу после создания.
4. Откройте popup расширения, вставьте токен и нажмите Сохранить.

Токен хранится в chrome.storage.local конкретной установки расширения. Он не включается в экспорт настроек и не зеркалируется через Chrome Sync.

Расширение использует актуальный REST-хост invest-public-api.tbank.ru. В GetCandles и GetLastPrices передаётся поле instrumentId; значением пока служит FIGI, что разрешено текущим контрактом T-Invest API.

## Сертификаты API на Windows

T-Invest API использует российскую TLS-цепочку НУЦ Минцифры. Без неё Chrome завершает соединение до проверки токена, а расширение показывает статус сеть/сертификат.

Установка корневого сертификата имеет важный компромисс: Windows и приложения, которые используют её системное хранилище, начинают доверять сертификатам, выпущенным этим удостоверяющим центром. Это расширяет круг центров сертификации, способных подтверждать HTTPS-сайты. При ошибочной выдаче сертификата или компрометации инфраструктуры такого центра теоретически увеличивается поверхность атаки.

Сертификат сам по себе не получает доступ к брокерскому счёту, токену или файлам. Основной практический риск возникает, если установить поддельный сертификат или установщик. Поэтому:

- загружайте сертификаты только с gosuslugi.ru/crt, на который ссылается официальная документация Т-Банка;
- не устанавливайте сертификаты из писем, мессенджеров, облачных дисков и сторонних инструкций;
- не запускайте Chrome с флагом --ignore-certificate-errors и не отключайте проверку HTTPS;
- используйте для расширения токен только для чтения.

Альтернатива системной установке — браузер со встроенной поддержкой российских сертификатов, например Яндекс Браузер или Атом. Совместимость текущего side panel расширения с ними отдельно не проверена, поэтому для маминого Windows-компьютера основной проверяемый вариант — Chrome плюс официальные сертификаты.

## Запуск

1. Откройте https://www.tbank.ru/terminal/
2. Дождитесь появления виджета Сканер цены MOEX.
3. Проверьте статус в заголовке виджета. При настройке IMOEX обычно отображается несколько десятков активных тикеров.
4. Откройте popup расширения и нажмите Тест-алерт.
5. В таблице должна появиться строка TEST +0.77%.

Если включён звук, тестовый алерт должен сопровождаться коротким сигналом. На Windows это необходимо проверить отдельно после установки: Chrome может ограничивать запуск WebAudio до первого взаимодействия со страницей.

## Настройки

| Настройка | Назначение |
|---|---|
| Порог изменения, % | Минимальный модуль изменения цены для алерта |
| Окно, секунд | Интервал сравнения цены: 60, 120, 300 или 600 |
| Cooldown, секунд | Минимальный интервал между алертами одного тикера |
| TTL записей | Время хранения строки в таблице |
| Акции IMOEX | Компоненты индекса IMOEX |
| Все российские акции | Все найденные рублёвые акции на площадках MOEX |
| Фьючерсы | Найденные инструменты FORTS/MOEX |
| Звуковой сигнал | Короткий сигнал при появлении новых строк |

До исправления расчётного буфера не используйте окно 600 секунд для принятия решений.

## Интересные и скрытые тикеры

У тикера есть три состояния:

- интересный, отмечен звездой;
- скрытый, исключён из сканирования;
- нейтральный.

Управлять состоянием можно в строке виджета или в popup, в секции Тикеры.

Опция Сканировать только интересные превращает список со звездой в whitelist.

Списки интересных и скрытых тикеров:

- хранятся локально;
- зеркалируются в chrome.storage.sync, если синхронизация Chrome доступна;
- экспортируются в JSON кнопкой Экспорт;
- восстанавливаются кнопкой Импорт.

Токен в JSON не попадает.

## Активация тикера в терминале

Клик по тикеру запускает безопасную трёхступенчатую стратегию:

1. Direct: поиск видимой строки терминала по data-row-id и обычная эмуляция клика.
2. Search-flow: открытие поиска терминала, ввод точного тикера и клик по строке результата a.pro-menu-item.
3. Text fallback: поиск точного текста тикера в DOM и клик по ближайшему интерактивному элементу.

Search-flow был проверен на акциях и фьючерсах. Он зависит от DOM терминала и может перестать работать после обновления интерфейса Т-Банка.

Активная версия не читает React fiber, не модифицирует Redux store терминала и не перехватывает window.fetch.

## Как выбирается цена

- Content script запускает цикл примерно каждые три секунды.
- GetLastPrices вызывается пакетами до 200 FIGI.
- Один тикер может присутствовать на нескольких площадках.
- Для каждого FIGI хранится отдельный ценовой буфер.
- Активная площадка выбирается по самому свежему времени последней сделки.
- Изменение рассчитывается только внутри буфера выбранного FIGI.
- Цена старше одного часа считается неактивной.
- Cooldown применяется к тикеру целиком, а не к отдельному FIGI.

Раздельные буферы защищают от ложных импульсов при различии цен основной, вечерней и выходной площадок.

## Хранение данных

| Данные | Хранилище | Фактическое поведение |
|---|---|---|
| Токен и основные настройки | chrome.storage.local | Сохраняются до удаления расширения |
| Интересные и скрытые тикеры | local + sync | Могут восстановиться через Chrome Sync |
| Алерты и статус | chrome.storage.session | Хранятся в памяти расширения |
| Буфер цен | Память content script | Теряется при перезагрузке страницы |

Несмотря на наличие алертов в storage.session, текущий content script не восстанавливает таблицу после перезагрузки терминала. Таблица начинает заполняться заново.

## Smoke-тест на Windows

1. Оставить включённой одну копию расширения.
2. Проверить установку сертификатов НУЦ Минцифры и полностью перезапустить Chrome.
3. Установить окно 60 секунд и порог 0.5%.
4. Открыть терминал и проверить появление виджета.
5. Убедиться, что статус не показывает сеть/сертификат или токен невалиден.
6. Нажать Тест-алерт и проверить строку TEST.
7. Проверить звук.
8. Кликнуть по тикеру из popup и проверить переключение терминала.
9. Кликнуть по тикеру в таблице сканера и повторить проверку.
10. В торговое время временно установить порог 0.05% и дождаться реального сигнала.
11. Убедиться, что один тикер не появляется одновременно несколько раз из-за разных площадок.
12. Вернуть рабочий порог после проверки.

Сравнение процента со встроенными колонками терминала является полезной исследовательской проверкой, но не считается строгим ожидаемым результатом: источники и момент сэмплирования могут отличаться.

## Известные проблемы

1. Расчёт начинается до накопления полного окна.
2. Окно 600 секунд фактически использует более короткую историю.
3. Для HTTPS-доступа к T-Invest API в Chrome требуются сертификаты НУЦ Минцифры в системе.
4. Статус сеть/сертификат объединяет несколько причин: недоверенный сертификат, недоступность сети, блокировку провайдером или VPN.
5. Таблица алертов не восстанавливается после перезагрузки страницы.
6. DOM-селекторы активации зависят от интерфейса терминала.
7. Несколько одновременно включённых копий расширения могут удваивать polling и создавать гонки.
8. Автоматических тестов пока нет.
9. Иконки расширения отсутствуют.
